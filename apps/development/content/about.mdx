# Adam M. Young

Senior Software Engineer at **9fin**, building fast, data-heavy tools and
sites in React. Outside of work I'm a photographer, a hiker, and an
_occasional_ runner.

I care about the boring things that make software good: fast feedback loops,
small bundles, accessible interfaces, and code the next person can read
without a decoder ring.

## What I work with

- **Frontend:** React, Next.js (App Router, RSC), TypeScript, CSS that
  doesn't need a framework to be maintainable
- **Backend:** Node, Postgres, Redis, edge/serverless runtimes
- **Infra:** Vercel, Cloudflare, Docker, boring CI that just works

## This site

It's a CRT desktop rendered entirely in CSS — no WebGL for the tube or the
grid. The synthwave motion respects `prefers-reduced-motion` and the toggle
in the top-right. The two games _do_ use a renderer (PixiJS), but it's only
downloaded if you open one.
