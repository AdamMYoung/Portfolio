**TrailWise** is a hiking, gear, and social platform for tracking mountain
peak summits and trail routes worldwide. It features historical timeline tracking, gear
management, trip planning, and social features, as well as offline LLM and smart watch support.

The website is built on Next.js Server Components backed by FastAPI, Postgres and Redis. Mobile is a cross-platform Flutter app, 
with offline LLM support built on Google's Gemma 4 model. **Trailwise** also exposes an MCP server so assistants can query your own hiking data.
