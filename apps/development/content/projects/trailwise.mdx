**TrailWise** is a hiking, gear, and social platform for tracking mountain
peak summits and trail routes worldwide — historical timeline tracking, gear
management, trip planning, and social features.

Built on Next.js Server Components backed by Postgres and Redis. It also
exposes an MCP server so assistants can query your own hiking data.
